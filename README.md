# PinPain female anatomy assets

Female body for the PinPain harness, served to the web UI via jsDelivr.

Extracted from `https://cdn.humanatlas.io/digital-objects/ref-organ/united-female/v1.5/assets/3d-vh-f-united.glb`
(NIH Human Reference Atlas, Visible Human Female v1.5), split per system, degenerate triangles removed,
simplified (nerves 50%, skin 40%) and Draco-compressed with @gltf-transform.
© HuBMAP Consortium / NIH, **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/),
derived from the Visible Human Female dataset of the U.S. National Library of Medicine.
888 named structures; `female.json` is the catalog (id, name, system per part).

Anatomical data is for orientation and communication with care providers - not a diagnostic tool.
